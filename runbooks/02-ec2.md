# Runbook 02 — EC2 High CPU / Disk / Unreachable
1. Confirm instance ID, region, AZ, role, ASG membership and impact.
2. `aws ec2 describe-instance-status --instance-ids <ID> --include-all-instances`.
3. Review CPU, network, memory/disk (agent metrics), status checks and recent ASG/deploy events.
4. Linux: `uptime; top; ps aux --sort=-%cpu | head; free -h; df -h; df -i; systemctl --failed; journalctl --since "30 minutes ago"`.
5. Unreachable: inspect SSM status, instance profile, routes, SG/NACL, DNS, OS firewall and listener. Prefer Session Manager.
6. Disk full: identify growth/owner; never delete unknown or database files.
7. Restart/reboot/replace only after approval, stateful-workload review and recovery plan.
8. Validate status checks, access, application health and resource stability.
